_Your daily dose of infosec chaos_

---

If your patch queue was looking suspiciously empty, today fixes that. PHP is dropping another critical RCE fix, NVIDIA is doing the "we are investigating" dance after a ransomware crew came knocking, and the tools you build software and store data in are catching memory-corruption heat left and right. At least one ransomware crew is trading its leak site for a jail cell, so there is that.

### PHP Drops Another Critical RCE, And The Fix Lands Today

PHP is shipping critical security releases today to patch CVE-2026-115560, a remote code execution flaw in the session upload progress feature, landing just days after the PHP2Shell fixes.
This is the second critical RCE out of PHP this month, and it hits every supported version - so much for that "we already patched PHP" feeling from last week.

**What to do:** Apply today's PHP releases as soon as they drop, and treat any internet-facing PHP app as priority one - again.

---

### NVIDIA Starts Investigating A Gentlemen's Ransomware Claim

The "Gentlemen" ransomware group added NVIDIA to its dark web leak site, and NVIDIA says it is investigating the claims.
Nothing is confirmed leaked yet, but this is a pattern worth watching: big-name vendors are increasingly the target, and "we are investigating" tends to quietly become "some employee data was accessed" a few weeks later.

**What to do:** If you rely on NVIDIA infrastructure or portals, monitor for unusual account activity now and keep an eye on official disclosures before sounding the alarm.

---

### Low-Priv Database Accounts Can Still Run Code On The Server

A researcher published proof-of-concept exploits showing that a restricted database account - one that cannot even read an application table - can hit memory-corruption bugs through ordinary SQL and win RCE on PostgreSQL, MySQL, and Oracle servers.
Your carefully scoped database permissions mean a lot less when the engine itself can be coaxed into executing code - least privilege does not cover the parser.

**What to do:** Keep database engines current, review who holds even "harmless" low-priv accounts, and monitor for unusual SQL patterns hitting your DB servers.

---

### Ruby Fixes Seven Memory-Safety Bugs, Five With Working RCE

Ruby released fixes for seven flaws in its regex engine and string case-conversion code, and maintainers warn that proof-of-concept exploits already show five of them can run arbitrary code from crafted input.
Regex and string handling are exactly the code paths every Rails app hits constantly, so "patched in the interpreter" is doing a lot of heavy lifting in that sentence.

**What to do:** Update Ruby to the patched releases across CI, production, and developer machines, then rebuild anything that statically embeds the runtime.

---

### Ransomware Crew's $40M Run Ends In Handcuffs

Ukrainian authorities, working with the FBI, arrested four suspected members of an international ransomware operation tied to at least 28 victim companies and more than 40 million dollars in ransom payments.
It will not end ransomware - the affiliate model is a hydra - but every takedown raises the operating cost of the business and occasionally yields infrastructure and decryptors.

**What to do:** Keep your defenses up anyway, but take the win: test your backups today while nobody is encrypting them.
